y = [x] - The Greatest Integer Function (Floor Function)

Introduction to y = [x]

The Greatest Integer Function, denoted as y = [x] or f(x) = ⌊x⌋ (also known as the floor function), outputs the largest integer that is less than or equal to x.[1]

Visually, y = [x] produces a characteristic staircase graph composed of horizontal line segments. For any real input x in the interval [n, n+1) where n is an integer, the value of f(x) remains constant at n.

Origin and Historical Context

The concept of rounding down to the nearest integer has been used implicitly since ancient mathematics. In 1808, Carl Friedrich Gauss introduced the bracket notation [x] in his work on quadratic reciprocity.

In 1962, Kenneth E. Iverson introduced the terms floor and ceiling along with the floor notation ⌊x⌋ while defining the APL programming language. Today, both bracket [x] and floor ⌊x⌋ notations are widely standard across mathematics and computer science.

Core Properties

The domain of y = [x] is all real numbers (−&infty;, +&infty;). The range is the set of integers ℤ. The function features jump discontinuities at every integer value.

The slope (derivative) f'(x) = 0 for all non-integer inputs, while the derivative is undefined at integer jump points where the function steps up by 1.

Worked Examples

If x = 2.7, then y = [2.7] = 2. If x = -1.4, then y = [-1.4] = -2. Note that for negative numbers, rounding down moves to the next smaller integer to the left on the number line.

A sample table of values demonstrates the step behavior:

x: -2.5 → y: -3 x: -1.0 → y: -1 x: -0.4 → y: -1 x: 0.0 → y: 0 x: 1.8 → y: 1 x: 2.7 → y: 2 x: 3.0 → y: 3

Scientific and Engineering Uses

Signal Processing & Digitization: Analog-to-Digital Converters (ADCs) quantize continuous analog signals into discrete voltage levels using floor function steps.[2]

Computer Science & Data Structures: Greatest integer functions determine hash table bucket indices, binary tree depth bounds, discrete event scheduling ticks, and integer arithmetic operations.

Real-Life Uses

Tiered Pricing & Metered Services: Parking garage rates, taxi meter charges, and cellular data plans charge in full-step increments based on floor function rules.

Postage & Shipping Rates: Package shipping costs are calculated based on whole-pound or whole-kilogram step tiers.

Age in Years: Human age is conventionally calculated as [age] in completed full years.[3]

How Transformations Work

Combining [x] with x yields the fractional part function {x} = x - [x]. Transformations like y = a[bx + c] + d scale step height (a), step width (1/b), and shift step origins.
